Line-art system

Control Room: the live part of the trace glows signal green. Glow is a drop-shadow recipe, used on live traces only.

Datasheet: the same drawing, flat ink, no glow. Rules for both: 1 px strokes (3 px for the signal trace), 45° and 90° turns only, vias are 4 px rings, pads are 6×10 rounded rectangles, grid cell 32 px with an 8 px fine grid.
